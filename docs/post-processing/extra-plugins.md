# Extra premium plugins

Superfunky's premium companion plugins extend a store without placing unrelated
features in the theme. Each plugin is intended to remain independently installable,
licensed, updated, and supported.

> **Pre-release notice:** The descriptions below outline the planned product catalogue.
> They are not installation instructions or a claim that every feature is currently
> available. This page will be expanded with requirements, setup, and operational guides
> as each plugin is released.

## Google Maps Locations

A store-locator plugin for managing locations, addresses, opening hours, contact details,
map markers, and display order in WordPress. Its planned storefront integration includes
map and list views, text and radius filters, geolocation, and shortcode rendering.

A Google Maps account, correctly restricted browser API key, and any provider usage
charges remain separate from the plugin licence.

## Slack Notifications

A theme-independent notification centre for sending selected WordPress, WooCommerce,
form, and system events to Slack through an incoming webhook. Planned controls include
independent event switches, message presentation, connection testing, and delivery logs.

The Slack workspace, webhook permissions, retention, and provider availability remain
the site owner's responsibility.

## Discord Notifications

A notification centre for sending selected WordPress, WooCommerce, form, and system
events to Discord using native webhook embeds. It is planned to offer event coverage,
connection testing, and delivery visibility comparable to the Slack companion while
retaining Discord-specific presentation.

The Discord server, channel permissions, webhook security, and provider policies remain
external to Superfunky.

## AI Shopping Assistant

A configurable storefront assistant intended to help visitors discover and compare
products through a connected AI service. Planned controls cover service connection,
storefront placement, visibility, branding, greeting text, privacy information, and
consent.

AI models, service accounts, API usage, content governance, and usage charges may be
licensed or billed separately.

## Abandoned Carts

A headless cart-recovery companion intended to retain consented cart snapshots and help
administrators follow recovery activity. Its planned scope includes an abandoned-cart
archive, customer timeline, recovery status, reminder sequences, coupons, unsubscribe
handling, and retention controls.

Newsletter consent is not abandoned-cart consent. The released plugin documentation
will define the lawful capture flow, scheduler, email transport, recovery links, and
data-retention requirements.

## Premium Plugin Bundle

The Premium Plugin Bundle groups all five companion plugins:

- Google Maps Locations;
- Slack Notifications;
- Discord Notifications;
- AI Shopping Assistant;
- Abandoned Carts.

The bundle is intended for stores that need the complete companion catalogue under one
commercial package. The plugins remain separate WordPress components with their own
settings and operational dependencies; buying the bundle does not include Google Maps,
Slack, Discord, AI, email, or other third-party accounts and usage charges.

Theme Pro is a separate product entitlement unless a sales package explicitly includes
both Theme Pro and the plugin bundle. Confirm current availability, licensing, site
limits, and support terms before purchase or deployment.
